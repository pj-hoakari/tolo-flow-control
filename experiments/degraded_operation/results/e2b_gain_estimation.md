# E2(b): 保存則による相対ゲインの推定

## 要点

エンジンが 1 リクエストで見る 30 分（Δt=30 秒で 60 窓）と、上流の観測サービスが持つ 30 日（86400 窓）での、iv 推定の相対誤差 中央値 / p90（流量 20 人/分、自由点 9 × 50 シード）。

| 観測モデル/流れ | 60 窓（30 分） | 86400 窓（30 日） |
|---|---|---|
| poisson/bidir | 340.9% / 8450.3% (欠測 219/450) | 29.8% / 64.2% (欠測 9/450) |
| poisson/oneway | 93.9% / 2251.2% (欠測 221/450) | 8.6% / 21.1% |
| thinned/bidir | 88.3% / 1298.6% (欠測 160/450) | 4.2% / 16.8% |
| thinned/oneway | 50.0% / 897.5% (欠測 172/450) | 1.5% / 4.4% |

## グラフと設定

devtools の grid(3,3) を土台にした。四隅が入退出点、内部 5 ノードが通過専用ノードで、全 12 エッジに方向別のラインカメラを置く。全エッジが少なくとも 1 つの通過ノードに接するので、保存則だけで全点を参照点とつなげられる。これを「通過ノードが全観測」の基準形とした。識別不能の検出を確かめるため、次の 3 つを意図的に加えた。

- 未観測エッジ e10（n2_0–n2_1）。n2_1 の保存則が使えなくなり、n2_1 と隅の n2_2 を結ぶ e11 は制約を持たない。
- e_kiosk。入退出点 n0_0 と目的地 kiosk を結ぶ。通過ノードに接しない。
- 孤立部分 isl_a–isl_t–isl_b。内部では保存則が成り立つが、参照点とはつながらない。

参照点は e0、使える通過ノードは ['n0_1', 'n1_0', 'n1_1', 'n1_2', 'isl_t']、参照点とつながる自由点は 9 個。経路数は bidir（全端点対、両向き）が 52、oneway（西の端点から東の端点へだけ）が 17。

真の流量は経路単位で与える。各経路の率は AR(1) の対数正規過程で、相関時間 10 分、対数標準偏差 0.4。経路の流量を足すので、通過ノードの保存則は真の流量で厳密に成り立つ。g_e は [0.6, 1.5] の対数一様。シードは各設定 50。窓数は最長 30 日分までとした。流量水準は参照点とつながる点の平均エッジ流量（両方向の和、人/分）で表す。観測モデルは 2 つ用意した。

- poisson: 観測カウント ~ Poisson(g_e·λ_e·Δt) をエッジ・方向ごとに独立に引く。依頼文の「保存則に従う真の流量に Poisson のカウント雑音」をそのまま読んだもの。到着のゆらぎもすべて観測雑音として扱うので、窓ごとの保存則は期待値でしか成り立たない。悲観側。
- thinned: 経路ごとの人数を Poisson で引き、真の人数は窓ごとに保存則を厳密に満たす。カメラは一人ずつ g≤1 なら確率 g で数え、g>1 なら確率 g−1 で二重に数える。雑音は検知の取りこぼし・二重計数だけになる。楽観側。

## 推定式

未知数は逆ゲイン h_e = 1/g_e。通過ノード v と窓 t ごとに Σ_e h_e·(流入カウント − 流出カウント) = 0 が成り立ち、h について線形・斉次になる。斉次なので全体の倍率は決まらない。参照点の h を 1 に固定して右辺へ移し、最小二乗で解く（ols）。説明変数のカウント自体が雑音を含むので、ols は h を 0 側へ縮める（errors-in-variables の減衰）。そこで正規方程式 AᵀA から雑音分散の期待値 D を引く補正版（corrected）も用意した。D は対角で、D_ee = Σ_(行) Σ_方向 y_e。poisson モデルの分散 = 平均を観測カウントで推定している。thinned モデルでは分散が g(1−g) 倍に小さく、この D は過補正になる。3 つ目の iv は、1 窓前の同じノードの行を操作変数にする。観測雑音は窓ごとに独立で、経路配分は相関時間をもって続くので、Σ_t a_(t−1)ᵀ a_t h = 0 は雑音分散を知らなくても偏らない。代わりに、配分が窓をまたいで続く成分しか使えない。解く前に、参照点と保存則でつながらない点（構造判定）と、設計行列の零空間に重みを持つ点（数値判定）を除外し、値を出さずに理由を返す。h ≤ 0 になった点も値を出さない（表の「欠測」）。

## 前提の確認

| 確認 | 結果 |
|---|---|
| 真の流量の保存則残差（最大） | 1.1e-14 |
| thinned の真の人数の保存則残差 | 0（assert） |
| 雑音なし・ols の最大相対誤差 | 4.9e-15 |
| 流量 10 万倍・poisson・corrected の最大相対誤差 | 0.4% |
| 構造判定の識別不能点 | e11, e_isl1, e_isl2, e_kiosk |
| 数値判定（雑音なしの設計行列の零空間）の識別不能点 | e11, e_isl1, e_isl2, e_kiosk |
| 参照点とつながる自由点の列の階数（経路配分が変動、雑音なし） | 9/9 |
| 同（経路配分が一定、σ=0、雑音なし） | 4/9 |

構造判定と数値判定は一致した。数値判定は雑音なしのデータで行った。雑音があると孤立部分の斉次な式は数値上は正則に見え、最小二乗は h=0（ĝ=∞）を返すだけになるので、構造判定のほうを推定の前段に置いている。経路配分が一定だと階数が落ち、窓をいくら増やしても推定できない。効くのは窓の数そのものではなく、経路配分が独立に変わった回数である。

## この数字が別のものを測っている可能性

- 推定式の偏り: ols は errors-in-variables で縮む。窓を増やしても ols の誤差が下げ止まるなら、それはデータ量の不足ではなく推定式の偏りである。corrected・iv との差がその大きさを示す。thinned では corrected の D が過補正になるので、モデル比較の表は iv に絞った（corrected の値も JSON にある）。
- 観測モデル: poisson と thinned は両端の想定で、実際のカメラはその間にある。窓をまたぐ滞留（通過ノード内の移動時間で、ある窓の流入が次の窓の流出になる）はどちらにも入れていない。30 秒窓ではこれが残差を増やし、必要な窓数を増やす方向に効く。
- 経路配分の変動量: 必要な窓数は σ と相関時間に強く依存する。相関時間の表のとおり、効くのは窓の数より独立な配分変化の回数である。実際の会場の配分変動はまだ測っていない。
- 流れの向き: bidir と oneway の差は、正味の流れと総数の比で決まる。実際の通路でこの比を測る必要がある。
- グラフの偏り: grid(3,3) は全エッジが通過ノードに接する好条件の形である。E2(c) の表のとおり、devtools の 11 シナリオのグラフで使える通過ノードは、5 つが 0 個、5 つが 1 個、crossing-detour だけが 3 個である。
